# prereg/ — pre-registrations of *Train After You Measure*

The two registrations of *Train After You Measure: a Pre-Registered Learning Curve for Fine-Tuning Typed Decision
Models on One User's Labels* (companion to arXiv:2610.32955), published at tag `v2.4`. Both were first committed in the
author's private repository `foyer` (branch `v3`); the commit hashes below refer to that repository. A public copy
shows the content; the dates rest on the private history.

| File | Registration | Original commit(s) |
|---|---|---|
| `PREREGISTRAZIONE_multiutente.md` | M (preliminary): multi-user hypotheses H1–H5, 30 Oct 2026 | `56b2970` (2026-10-30 14:47:28 +0100) |
| `PREREGISTRAZIONE_curva.md` | C (main result): learning curve on a fixed test set, 5 Nov 2026, with Amendment 1 | `96a3b7b` (2026-11-05 11:19:28 +0100); Amendment 1 `3d88d63` (12:53:29), which replaces `046cf50` (11:46:26) |

The texts are verbatim, in Italian, as registered. The only changes are privacy redactions, marked `[redatto: ...]`
(in C: the hash prefix of the private corpus, two local file paths and the name of the private Kaggle dataset), the
word "(private)" after the original repository's address in C, and an English note at the top of each file.
Hypotheses, thresholds, dates and design are unchanged.
